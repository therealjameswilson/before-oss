code pages were inspected before any selected field was interpreted.

Research proceeded through NARA index context, CIA Reading Room discovery,
exact-name and meaningful variant OSS searches, employer and occupation
searches, institutional records, obituaries, directories, newspapers and the
current Library of Congress search API. Library of Congress discovery was broad
rather than identity-specific: it returned 257 results for Charlotte Clayton,

Joseph P Cleary, one for Malachy F Cleary, four for Alice B Cleaveland, one for

item supplied a new identity-and-OSS bridge or named pre-OSS employer.

The user-supplied NARA Catalog API credential was not used. No raw Army row,
full private identifier, live API response, home address, phone number,
relative detail or family-sensitive data is retained here. Search snippets,
commercial people finders, unsourced genealogy and name-only biographies were
rejected as final evidence.

  Yugoslavia. A different Michael Cleffi reported killed in Normandy in 1944

  employment, but no source directly connects the Ohio State instructor to the
  indexed OSS file or proves that Ohio State was the immediate predecessor.
- Joseph P Cleary's five exact-name Army candidates all carry other eight-digit
