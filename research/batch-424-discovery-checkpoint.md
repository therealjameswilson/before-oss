source rows were compared with the complete 9,200,232-row Army Serial Number

stages. Search snippets, commercial people finders, genealogy-only pages and
name-only biographies were rejected as final evidence.

No raw Army row, full private identifier, authenticated API payload, home
address, phone number, relative detail or family-sensitive data is retained in
this checkpoint. The user-supplied NARA API key was not used.

## Source-specific cautions

- The Army merged file is incomplete, especially for officers. A missing row
  is not negative proof and does not identify a service branch.
- Richard E Clark's identifier-matched row records a 7 May 1942 Army entry,
  private grade and occupation value 736. The rendered official code page
  labels 7-36 as chauffeurs and drivers, bus, taxi, truck, and tractor. It does
  not identify an employer, vehicle, route, work location or actual work date.
- Roger A Clark Jr.'s row is an Enlisted Reserve Corps statistical card. The
  technical documentation shows that civilian occupation moves from columns
  70-72 to columns 71-73 on that layout. Reading the correct columns changes
  the value from an apparent 699 to 992. The rendered official code page labels
  9-92 as students. Student status is not employment, and the record does not
  name a school or establish that study immediately preceded OSS service.
- Russell W Clark's matched row records a 12 January 1944 entry and value 056,
  which the rendered official code page labels photographers. Its grade field
  contains the malformed value `750`; neither that value nor the branch field
  is expanded or used for personnel classification.
- Samuel E Clark's matched row records a 13 December 1941 Army entry and
  private grade. Its value 999 is not assigned an occupational label because
  the inspected summary pages do not define it consistently enough for this
  source context.
- Phillip H Clark, Randall E Clark, Richard N Clark Jr. and Robert G Clark
  retain their supplied identifiers in the private database, but none produces
  an Army-file match. Name-only records are not substituted.
- The exact-name Army search finds one Randall E Clark, twenty-four Richard E
  Clark, thirty Robert G Clark, one Roger A Clark Jr., eight Russell W Clark,
  seven Samuel E Clark, one Sherman W Clark and two Sidney E Clark rows. Exact
  identifiers select Richard, Roger, Russell and Samuel; every other row
  remains a separate person unless a second identifier beyond the name is
  established.
- Exact-name prewar directory results for Sherman W Clark and Sidney E Clark,
  and broader obituary, military and institutional namesakes, lack the indexed
  identifiers plus an OSS or chronology bridge. They are rejected as final
  evidence and no employer is transferred.
- An OSS personnel-file index row establishes that a file exists, not by
  itself the person's exact role or the chronology of every outside record.
