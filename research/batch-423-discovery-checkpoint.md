## Review method

PDF pages 82 and 83 were rendered at 150 dpi and inspected before research.
The ten source rows were then checked against the complete 9,200,232-row Army
Serial Number Merged File, its fixed-width technical documentation and the
rendered NARA occupational-code page needed for the selected record. The three
private identifiers printed in the cohort were compared without retaining
them here. Exact names, middle-initial and punctuation variants, OSS and CIA
context, employment and occupation terms, obituaries, institutional sources,
current Library of Congress discovery and broader archival discovery were
reviewed in stages. Search snippets, commercial people finders, genealogy-only
pages and name-only biographies were rejected as final evidence.

No raw Army row, full private identifier, authenticated API payload, home
address, phone number, relative detail or family-sensitive data is retained in
this checkpoint. The user-supplied NARA API key was not used.

## Source-specific cautions

- The Army merged file is incomplete, especially for officers. A missing row
  is not negative proof and does not identify a service branch.
- The occupation code is a broad historical category, not an employer,
  employing agency, specific job title or employment date.
- John M Clark's exact private identifier and exact indexed name select one
  Army row among thirty exact-name candidates. That row records a 2 September
  1943 Army entry, an enlisted grade and occupation code 266. The visually
  inspected code page labels 2-66 as policemen and detectives, public service.
  The evidence does not name the public agency or show that the work
  immediately preceded OSS service.
- John N Clark's printed `Maj` rank supports the existing commissioned Army
  classification at the source-record level. It does not select one of the
  thirteen exact-name Army rows or establish an outside biography.
- One Hoyt B Clark, 111 James E Clark, thirty John M Clark, thirteen John N
  Clark, one Leonard F Clark and four Leslie A Clark exact-name Army rows were
  reviewed as separate people. Only John M Clark's supplied exact private
  identifier selects an Army row.
- Leonard F Clark and Leslie A Clark retain their printed identifiers in the
  private database, but neither identifier produced an Army-file hit. The
  name-only records are not substituted.
- An OSS personnel-file index row establishes that a file exists, not by
  itself the person's exact role or the chronology of every outside record.
