## Review method

PDF page 83 was rendered at 150 dpi and inspected before research. Every
printed name, initial, rank or blank, private identifier or blank, box and
location in the ten-row cohort was compared with the immutable database. The
seven private identifiers were then compared transiently with the complete
9,200,232-row Army Serial Number Merged File. Exact-name candidates were
counted independently. The fixed-width documentation and the rendered NARA
code-list pages for the two selected records were inspected before any field
was interpreted.

Research proceeded through exact-name and variant OSS searches, CIA Reading
Room discovery, employer and occupation searches, institutional, obituary,
newspaper and archival searches, and the current Library of Congress search
API. The newspaper query behaved as broad token discovery rather than reliable
exact-name retrieval: it returned 3,338 results for Thomas, 328 for Vernon,
2,178 for Walter, 7,363 for each William query, 1,241 for Edward, 527 for
Frederick, 201 for Grace, 3,602 for James and 79 for Josephine. The first James
request timed out and succeeded on a bounded retry. No returned item supplied
the identity and OSS bridge required to select a person.

No raw Army row, full private identifier, API response, home address, phone
number, relative detail or family-sensitive data is retained here. Search
snippets, commercial people finders, unsourced genealogy and name-only
biographies were rejected as final evidence. The user-supplied NARA API key
was not used.

## Source-specific cautions

- The Army merged file is incomplete, particularly for officers. A non-hit is
  not negative proof and is never used to contradict Walter R Clark's printed
  Captain rank.
- Thomas B Clark's exact identifier and name select one official row, dated 25
  October 1943 and carrying an enlisted grade. Its civilian-occupation value
  031 is labeled by the rendered official code page as teachers (secondary
  school) and principals. The category does not name a school, employer,
  subject, position, location or actual employment date.
- William F Clark's exact identifier and name select one official row, dated 12
  October 1943 and carrying an enlisted grade. Its standard-card occupation
  value 992 is labeled by the rendered official code page as students. Student
  status is not employment; no school or immediate OSS predecessor is named.
- A circa 1909-1911 school-principal reference for a T. B. Clark is
  chronologically incompatible with the selected Thomas record and lacks an
  OSS bridge. It is rejected.
- A William F Clark obituary describing a 1923 birth, 1941 high-school
  graduation, January 1943 draft and later carpentry does not align with the
  selected Army row's recorded birth-year and October 1943 entry fields and
  supplies no OSS bridge. It is rejected. A different person born in 1943 is
  impossible for wartime OSS service.
- An Edward Clarke obituary describing wartime flight instruction and Turner
  Construction employment beginning in 1945 lacks any identifier or OSS
  bridge and cannot establish a pre-OSS employer for this common name.
- A Frederick C Clarke physician who died in 1941 cannot be the indexed OSS
  person. A namesake associated with the Corps of Engineers lacks the indexed
  identifier and OSS bridge.
- A James F Clarke on a field-artillery officer-candidate roster is a useful
  private lead but provides no second identifying fact. A DPAA result uses the
  Clark spelling and a different identifier. Neither is merged with the index
  entity.
- A 1940 college-marriage notice for a Josephine Clarke lacks an identifier or
  OSS bridge. It does not support student status, employment or identity here.
